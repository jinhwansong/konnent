# Konnect Frontend (Next.js)

## 1️⃣ 프로젝트 개요
멘토와 멘티의 연결부터 실제 세션까지의 전 과정을 매끄럽게 잇는 올인원 플랫폼의 사용자 인터페이스를 구현했습니다. 단순히 정보를 보여주는 것을 넘어, **예약 → 실시간 소통 → 결제**로 이어지는 복잡한 비즈니스 로직을 사용자 관점에서 단순화하고, 상태 변화를 실시간으로 체감할 수 있는 UX를 제공하는 데 집중했습니다.

## 2️⃣ 기술 스택
- **Next.js 15 (App Router)**: SSR을 통한 초기 렌더링 성능 확보 및 인터랙티브한 CSR 페이지의 적절한 조화.
- **TypeScript**: API 응답 구조 변경 시 UI 단에서 오류를 빠르게 인지하고 수정하기 위해 사용.
- **React Query**: 예약/세션 상태를 서버와 자동 동기화해 UI 불일치를 줄이기 위해 사용.
- **Zustand**: 모달 상태, 일시적인 UI 플래그 등 전역 상태를 오버헤드 없이 관리.
- **Socket.IO & WebRTC**: 실시간 채팅 및 화상 통화 시그널링을 위한 양방향 통신 구현.
- **Tailwind CSS & Framer Motion**: 생산성 높은 스타일링과 자연스러운 인터랙션 애니메이션 적용.
- **React Hook Form & Zod**: 복잡한 입력 폼의 유효성 검사 자동화 및 타입 안정성 확보.

## 3️⃣ 프론트엔드 아키텍처 포인트
- **데이터 관심사 분리**: 서버 상태(React Query), 전역 UI 상태(Zustand), 도메인 로직(Custom Hooks)을 명확히 분리하여 컴포넌트의 비대화를 방지했습니다.
- **공통 컴포넌트 설계**: 아토믹 디자인 패턴을 참고하여 버튼, 입력창, 모달 등 재사용성이 높은 UI 요소를 독립적으로 설계했습니다.
- **API 레이어 캡슐화**: `src/libs` 내에 도메인별 API 호출 로직을 모아 관리하고, 요청/응답 타입을 인터페이스로 정의하여 백엔드 변경에 유연하게 대응했습니다.

## 4️⃣ 핵심 기능 구현 디테일
- **예약 및 스케줄링**: `react-calendar`와 커스텀 로직을 결합해 멘토의 가능 시간을 직관적으로 선택하고 예약할 수 있는 UI를 구현했습니다.
- **리치 텍스트 에디터**: `TipTap`을 활용해 멘토가 지식을 공유하는 아티클 작성 기능을 구현하고, 이미지 업로드 및 포맷팅을 지원합니다.
- **가상 리스트(Virtualization)**: 대규모 채팅 내역이나 멘토 목록 조회 시 `react-virtuoso`를 적용해 메모리 점유율을 낮추고 스크롤 성능을 최적화했습니다.
- **통계 시각화**: 관리자 페이지에서 `Recharts`를 사용해 예약 현황 및 매출 데이터를 시각적으로 표현했습니다.

## 5️⃣ 성능 & UX 고려
- **이미지 최적화**: `next/image`를 사용해 기기별 적정 사이즈의 WebP 이미지를 서빙하고, LCP 영역의 우선순위 로딩(priority)을 설정했습니다.
- **코드 스플리팅**: 화상 채팅(`simple-peer`), 에디터(`tiptap`) 등 무거운 모듈은 필요한 라우트에서만 `dynamic import`하여 초기 번들 크기를 최소화했습니다.
- **사용자 피드백**: 결제 진행 중이나 실시간 연결 시 적절한 스켈레톤 UI와 토스트 메시지를 제공해 사용자의 불확실성을 해소했습니다.

## 6️⃣ 트러블슈팅
- **실시간 데이터 동기화 이슈**: Socket 이벤트 수신 시점과 React Query 캐시 갱신 시점 차이로 인한 UI 불일치 → Socket 수신 즉시 캐시를 무효화(invalidate)하거나 수동 업데이트하여 해결했습니다.
- **웹소켓 연결 안정성**: Next.js 개발 환경과 실 서버 간의 CORS 및 프로토콜 업그레이드 문제 → Nginx 프록시 설정에서 `Upgrade` 및 `Connection` 헤더를 명시하여 안정적인 웹소켓 채널을 확보했습니다.
- **번들 최적화**: 특정 페이지 진입 시에만 사용되는 라이브러리가 전체 메인 번들에 포함되는 현상 → 라우트 단위 코드 분할과 `lazy loading`을 적용해 초기 페인트 시간을 단축했습니다.
- 실시간/결제 흐름이 복잡해질수록 프론트 단에서 모든 상태를 제어하는 데 한계가 있음을 느꼈고,
  이후 백엔드 이벤트 기준으로 UI를 단순화하는 방향을 고민 중입니다.

## 7️⃣ 프로젝트 구조
- **src/app**: Next.js App Router 기반의 페이지 및 레이아웃 구성.
- **src/components**: 원자 단위부터 복합 도메인 단위까지 계층화된 UI 컴포넌트.
- **src/hooks**: 비즈니스 로직 및 실시간 이벤트 구독을 캡슐화한 커스텀 훅.
- **src/libs**: API 통신 함수 및 인증(NextAuth), 알림(Firebase) 설정.
- **src/schema**: Zod를 이용한 API 요청/응답 및 폼 데이터 유효성 검증 정의.
- **src/stores**: Zustand 기반의 UI 상태 관리 상점.

## 8️⃣ 테스트 및 개선 예정 사항
- **단위 테스트**: `src/libs/__tests__` 내에 결제, 예약, 세션 로직 등 핵심 비즈니스 로직에 대한 Jest 테스트 코드를 작성하여 안정성을 검증하고 있습니다.
- **진행 예정**: 복잡한 사용자 흐름(예약→결제→입장)에 대한 E2E 테스트(Cypress/Playwright) 추가 및 웹 접근성(ARIA) 준수율 향상.


## 9️⃣ 담당 범위
- **개인 프로젝트 전담**: 기획 보조부터 UI/UX 디자인 가이드 준수, 프론트엔드 아키텍처 설계, 모든 기능 구현 및 Vercel 배포를 단독으로 수행했습니다.
